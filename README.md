# 🌍 Trip Advisor – Travel & Tourism Website

Trip Advisor is a modern and responsive travel and tourism website designed to showcase popular destinations, travel experiences, and beautiful places around the world.

The website features a clean and professional UI/UX design with attractive destination cards, visually appealing layouts, and user-friendly navigation. Developed using HTML, CSS, and Tailwind CSS, the project focuses on responsive design, clean code, and a seamless browsing experience across all devices.

## ✨ Features

- Modern and professional UI/UX design
- Fully responsive website layout
- Explore popular travel destinations
- Attractive destination cards and image galleries
- Clean and user-friendly navigation
- Mobile, tablet, laptop, and desktop compatibility
- Tailwind CSS utility-based styling
- No JavaScript used

## 🛠️ Technologies Used

- HTML5
- CSS3
- Tailwind CSS

## 📱 Responsive Design

The website is designed to provide an optimal viewing experience across different screen sizes using Tailwind CSS responsive utility classes.

Supported devices:
- Mobile
- Tablet
- Laptop
- Desktop

## 🎯 Project Objective

The main objective of this project is to create a visually engaging and responsive travel website using modern frontend styling techniques, while maintaining simplicity, accessibility, and a consistent user experience without JavaScript.
